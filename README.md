# 灵感碎片 · 同人梗与番外便签系统 (SillyTavern 扩展)
> **Fragment Hub for SillyTavern (v1.18.0+)**

专为同人创作、跑团设定、对白脑洞与长篇番外设计的 SillyTavern（酒馆）全局便签本扩展插件。

---

## ✨ 核心特性

1. **全局便签本模式（方案 A）**
   - 跨所有角色与聊天全局共享灵感碎片库，随时记录与翻阅。
   - 数据直接持久化于酒馆 `extension_settings` 与本地存储，无需启动额外 Python 后端。
2. **酒馆聊天原生联动**
   - **一键填入输入框**：卡片列表及编辑弹窗均支持「填入」按钮，一键将碎片正文填入酒馆当前输入框（`#send_textarea`）并自动聚焦。
3. **9 大完整功能对齐独立版**
   - **灵感碎片 CRUD & 统计**：实时统计字数、行数、支持分类归档。
   - **多标签与分类系统**：支持分类气泡、标签池折叠展开、AND（同时包含）/ OR（包含其一）多标签组合过滤。
   - **批量管理**：批量改分类、批量追加标签、批量删除。
   - **双重查找替换**：单篇即时高亮替换 + 全局库内深度搜索替换。
   - **编辑区防误触**：支持 `Ctrl+Z` 撤回与 `Ctrl+Y` 重做历史快照栈（最多 50 步）。
   - **一键敏感词打码**：纯黑方块遮罩（████）、词库持久化管理、全局打码视图一键切换。
   - **莫兰迪排版卡片长图导出**：内置 5 款莫兰迪高雅配色（宣纸暖白、青竹灰绿、雾霾粉蓝、灰粉轻紫、玄青曜黑），支持 Retina 高清 PNG 导出、长文本平滑滚动预览、手机长按存相册、Web Share 系统原生分享。
   - **全量 JSON 备份与导入**：支持一键导出标准 JSON 备份、复制数据、选择历史备份文件一键恢复。

## 📦 安装方法

将本文件夹 `sillytavern-fragment-hub` 复制或移动至你的 SillyTavern 目录下的第三方扩展目录：

```bash
# 目标路径示例：
SillyTavern/public/scripts/extensions/third-party/sillytavern-fragment-hub
```

### 目录结构：
```text
sillytavern-fragment-hub/
├── manifest.json       # 扩展清单配置
├── index.js            # 核心业务逻辑与酒馆 API 桥接
├── panel.html          # 原生莫兰迪全功能 UI 结构
├── style.css           # 莫兰迪视觉样式与酒馆弹窗适配
└── README.md           # 使用说明文档
```

## 🚀 使用指南

1. **打开便签本**：
   - 启动或刷新 SillyTavern 页面后，右上角顶部导航栏会新增一个「灵感碎片」线条书页图标；
   - 点击即可呼出半透明毛玻璃全屏便签面板。
2. **快速填入对话**：
   - 在卡片流中看到心仪的梗或对白，直接点击卡片右下角的 **「填入」** 按钮；
   - 便签本会自动将内容插入酒馆输入框并关闭便签面板，方便立即发送给 AI 角色。
